# Room Finder AI

i will give 10 time tables please create web to findebsite must figure out which rooms are currently empty at any given time. The results must be neatly organized floor-by-floor.The AI Room Finder: Instead of forcing users to click through dropdown menus, integrate a smart text bar. A user should be able to type, "I need an AC room on the ground floor for me and my team for the next 2 hours." The AI must process this sentence, analyze the timetables, and spit out the exact rooms that match their specific needs and duration.
